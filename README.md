# Itera AI guidelines

Itera's shared knowledge base for AI-assisted work, for both people and agents.

- **Start here:** [index.md](index.md) lists everything.
- **Rules:** [guidelines/](guidelines/) holds the normative rules, such as the [AI-Fjellvettregler](guidelines/fjellvettregler.md).
- **Knowledge:** [wiki/](wiki/) holds practices, tool notes and lessons learned.
- **Skills:** [skills/](skills/) holds agent skills you can install.

## Contributing

Learned something others should know? Let an agent file it:

1. Clone the repo and open it in Claude Code, Copilot or another agent that reads `AGENTS.md`.
2. Say something like *"Add this to the wiki: …"* and paste or describe what you learned.
3. The agent finds the right page, removes anything confidential, updates `index.md` and prepares a PR. Check its work, then open the PR. A colleague reviews it.

**This repo is public.** No customer names, internal URLs, personal data, credentials or customer code. When in doubt, generalize or leave it out.

Changes to `guidelines/` are policy changes; discuss them with the AI guideline owners first.
