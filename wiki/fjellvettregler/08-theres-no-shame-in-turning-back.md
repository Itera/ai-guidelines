# 8. There's no shame in turning back

How to notice when AI work is going nowhere, and what to do then.

Rule: [AI-Fjellvettregler, rule 8](../../guidelines/fjellvettregler.md#8-theres-no-shame-in-turning-back)

## How to follow it

Warning signs:

- The agent fixes the same error over and over, or undoes its own changes.
- It changes tests to make them pass instead of fixing the code.
- You can no longer explain what it changed or why.

What to do:

- Stop the session. Don't keep adding "please try again".
- Start fresh with a clearer, smaller task and only the context it needs.
- Plan first: ask for a plan and review it before any code is written.
- Or do it yourself. Your judgment is the best equipment you have.
