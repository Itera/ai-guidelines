# 7. You own what you bring home

How to review AI output and keep key decisions with people.

Rule: [AI-Fjellvettregler, rule 7](../../guidelines/fjellvettregler.md#7-you-own-what-you-bring-home)

## How to follow it

- Review AI-generated code as carefully as a colleague's, against the customer's quality rules.
- Run the tests, and check that new tests actually test something.
- Look for security problems, made-up APIs and outdated dependencies.
- Question suggestions that push particular products, libraries or vendors.
- Keep key decisions with people: architecture, programming language, handover to operations. Record them, for example as ADRs.
